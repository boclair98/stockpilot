# 전체 종목 탐색·시세 경합 검증 (2026-10-27)

## 범위와 상태

코더스 웹의 기존 디자인을 유지한 추가 구현의 로컬 QA 기록이다. 사용자가 테스트 후 기존 GitHub 반영·코더스 웹 배포를 승인했다. 릴리즈는 canonical upstream→실제 fork 동기화→기존 코더스 프로젝트 배포→운영 검증 순서로 진행한다. 기존 계좌 데이터·주문 규칙과 비공개 앱인토스 소스/번들은 유지한다. 아래 목록 수·화면·검사는 로컬 검증 기준이며 운영 확인은 배포 후 별도로 수행한다.

## 확인한 결함과 수정

1. 전체 종목 목록은 순위 아래 접힌 영역에 있고 검색은 빠른 검색20개로 끝나기 쉬웠다. `/stocks` 별도 화면, 국가/거래소/검색/20·50·100개 페이지, 처음·다음·마지막·직접 이동과 URL 복원을 추가했다. 순위 제목·주요 메뉴·전체 메뉴·빠른 검색에 실제 링크를 연결했다. 순위와 전체 목록은 서로 다른 자료임을 유지한다.
2. 코스닥과 코스피의 마스터 꼬리 필드 길이가 달랐다. 개행을 제외한227/221문자로 읽고, CP949를 먼저 해독해 한글 종목명을 보존한다. 영문 포함6자리 코드를 복원하고9자리 펀드 식별자의 끝6자리를 주식처럼 만들던 처리를 제거했다.
3. 미국 종류주·우선주 등463개 티커가 `/`를 포함했다. 원본 식별자를 다른 티커로 치환하지 않고 URL query 인코딩과 상세·비교·순위·미국 상세정보 검사에 반영했다. 미국 기업정보의 슬래시 티커에는 query 기반 조회 경로를 추가했다. 미제공 SEC 자료를 생성하거나 다른 회사로 대체하지 않는다.
4. 실제 브라우저의 `BRK/B` 직접 상세 진입에서 초기 기본 시세/로컬 캐시가 나중에 전체 배열을 교체해 선택 종목을 지웠다. 종목ID·자료 시각으로 기본 목록, 캐시, WS, 상세 시세를 병합한다. 캐시는 실제 온라인 응답을 덮지 않고, 미래 날짜의 브라우저 캐시도 온라인 자료로 대체한다. 금액 계산이나 주문 규칙은 변경하지 않았다.
5. 시세가 아직 없는 미국 상세가 원화·KRX로 차트/기업정보를 요청할 수 있었다. 선택한 원본 식별자의 시장·거래소·통화를 사용한다. 직접 조회 실패는 지속적인 오류와 읽기 전용 재조회/다른 종목 찾기를 제공한다. 검증된 시세가 없으면 주문할 수 없다.
6. 시각 검토 후 검색 라벨의 시각적 숨김, 링크 밑줄, 로고 크기, 검색창 배경 충돌, 중복 테마 컨트롤, 열 제목 정렬, 모바일 도구 메뉴의 절반 폭 문제를 실제 수정했다. 페이지 이동 후 결과를 볼 수 있게 상태 영역으로 포커스/스크롤을 옮긴다.

## 미확인·제한

- 이 문서의 결과는 로컬 QA이며 운영 재배포·운영 회귀 검증은 별도 릴리즈 절차에서 수행한다. 실계정 쓰기·실기기 네이티브 테스트·4만 명 부하 테스트는 하지 않았다. Lighthouse/실사용자 CWV·INP 수치를 측정했다고 주장하지 않는다.
- 전체 목록은 KOSPI/KOSDAQ/NAS/NYS/AMS 제공 범위다. 선물·옵션·장외·다른 국가의 모든 상품은 아니다. 목록은 서버 시작 이후 공식 마스터 수신 기준이며, 매일 자동 갱신을 구현했다고 주장하지 않는다. 자료 시각을 시세 최신성으로 오인하지 않게 구분한다.
- 실제 종목별 시세 제공/거래정지 상태에 따라 모의주문 가능 여부가 다르다. 목록에 존재한다는 이유로 시세·체결을 만들어내지 않는다.
- 미국 SEC 기업공시는 기존 운영의 `SEC_USER_AGENT` 설정이 없는 상태로 앞선 운영 점검에서 확인됐다. 이번에 운영 설정을 읽거나 바꾸지 않았고, 새 query 경로만으로 SEC 자료가 제공된다고 주장하지 않는다.
- 기존 사용자 변경인 `frontend/components/LeagueRooms.tsx`와 `frontend/artifacts/`는 보존하고 이 작업의 수정 대상으로 취급하지 않는다.
