## 브라우저 확인

`PORT=5250 node scripts/preview-functional.mjs`는 운영 API에 접속하지 않는 명시적 로컬 검증 서버다. 다음 결과는 고정된 테스트 데이터에 대한 브라우저 검증이며 운영 사용자의 계좌를 수정하거나 시험 주문을 만들지 않았다.

- 투자 기록 20 → 40 → 43건 더보기, 마지막 페이지에서 더보기 제거.
- 회사명 + 미국 시장 + 매도 필터 조합, 날짜 하루 범위 6건 조회.
- 종료일이 시작일보다 이르면 오류 안내, 조회하지 않음.
- 서버 오류 안내 → 초기화/재조회 회복.
- 인증 만료 시 기존 개인 기록 제거 및 로그인 안내.
- 상세 주문 방식·체결가·수수료·세금·실현손익 표시 및 종목 상세 링크.
- 실제 CSV 다운로드, 코드 앞자리 0 유지, 미체결 금액 공란. CSV 수식 삽입 방어는 자동 테스트 포함.
- Tab 키 이동과 보이는 포커스, 금액 숨김 적용 확인.
- 360×800, 390×844, 768×1024, 1440×900 확인. 페이지 가로 넘침 없음. 라이트/다크 테마 확인. 데스크톱 검색/시장/매매 필터를 한 줄로 정리하고 모바일 기간/상태 필터는 접을 수 있게 구성.
- 관심종목 회사명/코드 검색·정렬·미수신 값 처리: 자동 테스트 확인.

## 2026-10-23 운영 검증 및 보완

- 첫 웹 배포가 `ready`에 도달했고 웹/API/worker 빌드가 모두 성공했다. `/healthz` 및 `/api/health/ready` 200, DB·공유 캐시 정상, 새 개인 기록 API 비로그인 401 확인.
- 운영 화면에서 새 투자 기록 로그인 안내, 실제 미국 종목 가격·통화·갱신 시각과 종목 상세 이동을 확인했다.
- 비로그인 브라우저에서 관심종목 1개를 임시 저장해 티커 검색·등락률 낮은순 선택·검색 결과 없음·조건 초기화를 확인한 뒤 테스트 항목을 제거했다. 계좌에 주문을 만들지 않았다.
- 운영 태블릿 검증에서 기존 자산 카드 라벨의 세로 줄바꿈과 KOSPI 그래프의 숨김 규칙을 발견했다. 자산 세부금액을 1열로 정리하고 태블릿 그래프 표시를 복원하는 CSS 후속 보완을 추가했다.

## 한계 및 운영 확인 범위

- 이름은 적재된 종목 카탈로그 기준이며, 없는 과거/상장폐지 종목은 코드로 표시한다.
- CSV는 현재 불러온 기록만 포함한다. 추가 페이지를 자동으로 전부 다운로드하지 않는다.
- 서로 다른 통화는 합산하지 않는다. 조회는 읽기 전용이며 체결을 수행하지 않는다.
- SQLite 단위 테스트와 로컬 UI 자료는 운영 PostgreSQL의 부하 시험이나 실제 Google 로그인 왕복 검증을 대체하지 않는다.
- 운영 배포 후에는 비로그인 접근 제어·새 화면·공개 시세/API·헬스와 모바일/데스크톱 렌더링을 별도로 확인한다. 로그인한 운영 계정의 전체 주문/저장 흐름은 이번 작업에서 실행하지 않는다.
- 로컬 검증 서버의 구현하지 않은 부가 개인 API는 의도적으로 404를 반환한다. 이를 새 기록 API의 정상 동작 증거로 사용하지 않는다.
- 실제 사용자 Core Web Vitals나 대규모 동시 접속 용량은 측정하지 않았으며 성능 수치를 주장하지 않는다.
