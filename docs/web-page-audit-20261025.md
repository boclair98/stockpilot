# 2026-10-25 StockPilot 웹 페이지 전반 감사

## 범위와 보존
- 사용자 제공 관심종목 사이드 패널의 필터/표시 개수/종목 행 문제를 공통 컴포넌트 수준에서 수정한다.
- 시장·상세·관심·자산·매매 기록과 비교/알림/계좌 도구/지원/리그/연습/성장/라운지/학습/프로필/안내·약관 페이지를 점검한다.
- 기존 브랜드, 다크 기본값, 사용자 선택 라이트 테마, 금액·계좌·실제 모의주문 계산 및 API 계약은 유지한다. 앱인토스·운영 DB·외부 공급자 설정 변경 없음.
- 기존 사용자 변경 `LeagueRooms.tsx`와 `frontend/artifacts/`는 커밋에서 제외한다.

## 검사 방식
- 실제 React 컴포넌트와 helper를 격리 hooks/fetch/타이머로 실행한다. 테스트를 위한 production API 교체·운영 계좌 쓰기 없음.
- 신규 `verify-workspace-audit.cjs` 17개: 필터·정렬·초기화/행 조작 분리/부분 저장 실패/수량 검증/연습 실패·종목 전환/리그 실패·복구/라운지 실패·빈 결과 및 게시 중 조회 경합/성장 실패/알림 입력과 뉴스 오류/기업정보 종목·응답 검증/로그인 조회 시간 제한/저장 응답 경합/CSS 구조/화면 전환 위치/상세 콘텐츠 즉시 마운트 검증.
- 기존 안전성 14종도 함께 실행: 요청/비교/시장 응답/기록 필터/탐색/통화별 자산/분석 복구/개인 쓰기·읽기/달력/미국 지표/차트/순위 비교/도구 접근.
- 변경 TS/TSX/CJS ESLint, production build와 TypeScript 검사. CSS 문자열 검사는 실제 브라우저 치수 검사를 대신하지 않는다.

## 브라우저·운영 검증과 한계
- 현재 브라우저에서 이미 열려 있는 운영 StockPilot은 접근 가능하여, 먼저 390px·1440px의 공개 16개 경로를 읽고 치수·주요 화면을 검사했다. 로컬 미리보기 접근은 이전 저장 정책상 차단되어 우회하지 않았다.
- 1차 배포 `fb88f9d`/`5565b9fb-e90b-4a11-8501-cc1227a25db2`는 ready였다. 운영에서 관심 검색→빈 결과→초기화와 순위 2종목 선택→실제 비교 시세 표시를 확인했다. 16개 공개 경로×4개 너비×양 테마(128조건)에서 페이지 가로 넘침이 없었다. 처음 theme 수화 전 측정된 다크4건은 theme 적용 후 다시 통과했다. 한국/미국 순위와 전체 종목 목록 각각20→40개 조회, Apple 상세·선/일봉 전환, 모바일 주문 시트 열기/Escape 닫기/진입 버튼 포커스 복귀를 확인했다. 실제 계좌 주문은 제출하지 않았다. 이 실제 감사에서 위 추가 읽기/관심 첫 화면/차트 위계 보완을 도출했다.
- 확인 가능한 계정은 게스트이며 로그인된 실제 계좌·실제 기기 푸시·수만 명 부하·장중 공급자 지연을 모두 실검증한 것은 아니다. 해당 쓰기 흐름은 기존 API/프론트 격리 회귀로 확인하며 사용자 데이터 보존을 우선한다.
- 투자 순위/시세의 제공 범위·권한·시장 휴장/공급자 장애는 화면 정상 렌더만으로 보장할 수 없다. 자료 시각과 오류를 숨기지 않는다.
