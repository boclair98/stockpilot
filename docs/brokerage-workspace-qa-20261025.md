# 증권형 웹 작업 검증 · 2026-10-25

## 범위

StockPilot 코더스 웹의 종목 탐색·차트·미국 핵심 지표·기능 바로가기만 보완한다. 기존 모의계좌 데이터, 주문 계산, 인증, 백엔드와 앱인토스 번들은 변경하지 않는다. 사용자 작업인 `LeagueRooms.tsx`·기존 `frontend/artifacts`는 게시에서 제외한다.

## 근거와 한계

공식 네이버·토스 공개 페이지의 메뉴/순위 구조를 읽었다. 미래에셋은 본문 추출이 되지 않았다. 참고 사이트 브라우저 권한은 거부되어 우회하지 않았으며, 타사 화면을 직접 시각 관찰했다고 주장하지 않는다. 기존 StockPilot 운영 화면과 실제 API·컴포넌트를 기준으로 설계했다.

추가 키·스키마 변경은 없다. 외부 데이터가 지연/누락/실패하면 해당 영역에 이를 표시한다. 기능 개수나 테스트 결과만으로 장애가 전혀 없거나 증권사와 동등한 실거래 시스템이라고 주장하지 않는다.

## 검증 기록

실행 결과:

- `verify:safety`의 기존10종+새4종, 총14개 스크립트가 모두 exit0으로 통과했다. 새 지표5개·차트4개·순위 비교4개·바로가기1개 사례는 실제 TS/TSX를 컴파일해 검사한다.
- Next.js16.2.2 webpack 프로덕션 빌드 exit0. TypeScript와24개 정적 경로 출력을 확인했다. 새 의존성·프레임워크 이전은 없다.
- 수정한 TSX/헬퍼/fixture 대상 ESLint 통과. CommonJS 검증 스크립트는 기존 Node CJS 실행 방식을 유지해 해당 import 규칙만 파일/CLI 범위에서 적용 제외했다. 기존 주문 이벤트의 실제 시각 검사와 외부 저장소 복원에는 의미를 설명한 좁은 lint 예외를 추가했으며, 금액·주문 규칙은 변경하지 않았다.
- diff 공백 검사, fixture JavaScript 구문 검사를 수행했다. 기존 전체 저장소 lint 무결성·무장애·부하 용량을 주장하지 않는다.
- 운영의 미국 history(AAPL/NAS/USD) 응답200·80행과 quote-details 응답200·시총/PER/52주 필드 존재를 읽기 전용으로 확인했다. 운영 계좌 쓰기는 수행하지 않았다.

브라우저 제한:

- 참고 사이트와 로컬 `http://127.0.0.1:5258/` 열기가 거부됐다. 사용자가 브라우저 검증을 다시 승인한 뒤에도 도구는 저장된 권한 또는 관리 정책의 차단을 보고했다.
- 이를 우회하는 다른 브라우저·원시 CDP·헤드리스 캡처를 사용하지 않았다. 이번 새 화면의360/390/768/1440px 실제 스크린샷·시각/키보드 전체 흐름·브라우저 콘솔/요청 검증은 미확인이다. 자동 component 검사는 실화면 검사와 같지 않다.
- 당초 실화면 확인이 불가능해 게시를 보류했다. 이후 미확인 제약을 명시한 질문에 대해 사용자가 다시 배포를 지시하여, 그 제약을 유지하고 upstream→실제 fork 동기화→기존 Coders 배포→서버/배포 자산 읽기 검증을 진행한다. 브라우저 차단을 우회하거나 실화면 검증을 완료했다고 주장하지 않는다. 최종 SHA·배포 ID·상태는 별도 로컬 릴리스 영수증과 완료 보고에 남긴다.

운영 계좌 쓰기·실제 Google 로그인·실제 푸시·다중 사용자 부하 시험은 범위 밖이다.

UI 검증용 `preview-functional.mjs` 자료는 명시적 격리 fixture이며 실제 시장/계좌 자료가 아니다. 실제 운영 시세나 계좌를 fixture로 대체하지 않는다.
