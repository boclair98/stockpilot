# 2026-11-06 웹 고도화 검증 기록

## 범위

코더스 StockPilot 웹의 전체 목록 비교·명시적 브라우저 검색 조건 저장, 빠른 검색 안정성, 프로필/공시 조회 복구, 시세 미확인 자산 표시를 개선했다. 기존 디자인·금융 계산·계좌 데이터·앱인토스·기존 LeagueRooms 사용자 변경은 보존했다. 새 라이브러리·DB migration·API 자격증명은 없다.

2차 추가: 실제 공통 거래일의 비교 종가 확인, 비교 링크/계정·브라우저 저장/뒤로가기의 기간 보존, 실패 종목 선택 보존·개별 재조회, 메모 저장 중 새 입력 보호, 캘린더 탐색 복원, 가격 알림 검색·범위·명시적 읽음 처리, 공통 저장 응답 검증과 관심종목 초기 상태 구분. 기존 서버의 COMPARE 저장 데이터에 선택 기간을 추가하고 가격 알림 조회를 감시 중20/최근 도달30으로 분리했다. 계좌·주문 계산 변경이나 데이터 마이그레이션은 없다.

## 실행 결과

- `frontend/package.json`의 `verify:safety`: 24개 스크립트 전체 통과. 실제 소스와 격리된 React/HTTP/storage 하네스로 검증하며 운영 응답을 꾸미지 않는다.
- `node scripts/verify-product-edition.cjs`: 11개 통과.
- 새 조건 저장/목록 통합 검사: 9개(기존 통합 4개 포함), 비교 검사: 7개, 빠른 검색: 5개, 프로필·공시 복구: 8개 통과.
- `node scripts/verify-holding-valuation.cjs`: 실제 보유 컴포넌트 SSR, COST 정렬·표시·호환·응답 검증 통과.
- `node node_modules/typescript/bin/tsc --noEmit`: 통과.
- 변경 TSX·helper 대상 `node node_modules/eslint/bin/eslint.js ...`: 통과. 최초 묶음 린트는 오래 대기하여 자체 프로세스를 중지했고, 범위를 나눠 다시 실행했다. 패키지 재설치/자동 purge는 수행하지 않았다.
- `node node_modules/next/dist/bin/next build --webpack`: 26개 정적 페이지 생성 성공.
- 2차 최종 소스에서 안전성24개 스크립트/제품11개를 재실행했고 모두 통과했다. 추가된 TSX·helper의 ESLint, 백엔드 변경의 Ruff, `tsc --noEmit --incremental false`와 최종 정적 빌드를 다시 통과했다. 의존성/lockfile·DB migration은 추가하지 않았다.
- `backend/unit_tests`에서 `../.venv/Scripts/python.exe -m pytest . -q -p no:cacheprovider`: 290개 통과. Firebase `MulticastMessage.tokens`의 기존 deprecation warning 3개는 남아 있다. 실제 푸시·계좌·시세 API는 호출하지 않았다.
- 2차 새 검사: 비교 복구10개, 메모/캘린더 연속성8개, 알림 관리7개 통과. `verify-workspace-audit.cjs`는 저장 데이터 검증·초기 관심 목록·날짜별 비교 조작5개를 추가해25개 통과. 백엔드 알림 관리5개·비교 기간19개가 전체 단위 검사에 포함된다.
- `git -c core.whitespace=cr-at-eol diff --check`: 통과. 기존 파일의 LF/CRLF를 일괄 변환하지 않았다.

- 원가 대체 보유분의 명시적 COST 상태, 해당 손익·수익률 표시 억제, 참고 합계·불완전 비중 안내, 수익률 정렬 마지막 배치. 기존 금액과 snapshot 입력의 계산이 그대로임을 격리 검사.
- 비교 공유 URL의 종목 식별자/기간, 부분·전체 조회 실패 후 선택 보존, 개별 재시도, 동일 저장 묶음 재개방 시 명시적 새 조회, 오래된 검색·클립보드 응답 차단, 공통 거래일·선택 표시·정확한 통화 값. 기존 저장 기간 누락은20일로 복원한다.
- 저장 도중 새로 쓴 내용·동일 문구로 되돌린 수정도 미저장 초안으로 보존, 저장 중 중복 클릭 차단, 계정/종목 변경 시 편집기 분리, 충돌/실패 후 초안 유지. 캘린더 월·선택 날짜는 목록 전환 뒤 복원하고 인증 변경 시 초기화한다.
- 알림 감시 중20개가 최근 도달30개에 가려지지 않음, 실제 전체 개수/조회 범위, 상태·종목·거래소 검색, 사라진 종목의 식별·삭제 가능 상태, 메뉴 열기와 이후 도달 이벤트가 자동 읽음을 발생시키지 않음. 명시적 모두 읽음은 단일 요청·영수증 검증·불확실 결과 재조회이며 자동 재전송하지 않는다.
- null·중복·잘못된 버전/도메인 저장 응답은 기존 목록을 대체하지 않음, 잘못된 삭제 영수증은 삭제 성공이 아님, 서버 기준1200 Unicode code point 메모 호환, 초기 관심종목 실패가 빈 목록이 아님.

## 아직 확인하지 못한 항목

Work 설정에서 로컬 브라우저 사용이 비활성화됐다. CUA의 브라우저 열기 응답이 `Local browser use is disabled in Work settings`여서 다른 자동화로 우회하지 않았다. 이번 변경의 360×800,390×844,768×1024,1440×900 light/dark 실화면·스크린샷·키보드 실제 조작·브라우저 콘솔 검증은 미완료다. 기존 스크린샷을 이번 증거로 재사용하지 않는다. Lighthouse/CWV·실사용 INP·대규모 부하는 측정하지 않았다.

브라우저 사용을 켠 뒤 격리 preview로 다음을 확인해야 한다:

```powershell
cd frontend
$env:UPGRADE_FIXTURE='1'
$env:PORT='5310'
node scripts/preview-functional.mjs
```

- `http://127.0.0.1:5310/?browse=all#market-rankings`: 검색/조건 저장/삭제 취소/국내·미국/비교/페이지 탐색.
- `http://127.0.0.1:5310/?release_case=valuation-cost#holdings`: 시세 없는 보유분과 참고 합계.
- `http://127.0.0.1:5310/?release_case=profile-retry#decision-review`: 계정 일시 실패와 재조회.
- `http://127.0.0.1:5310/notifications?release_case=disclosure-retry`: 일부 공시 실패 후 재조회.
- `http://127.0.0.1:5310/notifications?release_case=disclosure-all-failed`: 전부 실패를 빈 관심 목록으로 표시하지 않는지 확인.
- `http://127.0.0.1:5310/compare?items=KR%3AKRX%3A005930%2CUS%3ANAS%3AAAPL&days=20`: 공통 날짜 선택·이전/다음, 원화/달러 구분, 선택 표시와 값 일치, 기간 변경/Back/링크 복사. 합성 가격 경로이며 실제 시장 자료 검증이 아니다.
- 알림50개/부분 실패·메모 저장 경합·캘린더 과거 월 복귀는 현재 격리 React/SQLite 테스트로 검증했다. 실제 브라우저의 계정 저장 쓰기·알림 모두 읽음은 별도 승인된 시험 계정·서버에서 재확인해야 하며 운영 계정으로 대체하지 않는다.

이 preview의 숫자·종목·계정·공시는 명시적인 합성 fixture다. 운영에 배포하거나 실시간 시장 자료라고 설명하지 않는다. fixture의 1회 실패 시나리오는 프로세스 재시작으로 초기화된다. `PERSONAL_FIXTURE`는 사용하지 않는다(별도 서버 프록시 모드).

## 배포 상태

이번 턴의 새 GitHub·포크 반영/코더스 재배포 승인 응답은 아직 없다. 커밋·푸시·포크 동기화·배포·운영 계좌 요청을 수행하지 않았다. 사용자가 승인하고 시각 검증이 가능해지면 canonical upstream → 실제 fork 동일 SHA → 기존 코더스 배포 → ready → 운영 웹 확인 순서로 진행한다. 기존 운영 배포는 그대로다.
