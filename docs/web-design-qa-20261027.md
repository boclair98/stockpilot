# 2026-10-27 웹 디자인·기능 점검

## 범위와 보존

코더스 StockPilot 웹만 변경한다. 기존 Next.js/React, 인증·라우트·API·계좌·모의주문 계산을 유지한다. 별도 앱인토스 번들·광고 설정·검토 상태, DB 스키마와 서버 비밀 환경변수를 변경하지 않는다. 작업 전부터 존재한 `LeagueRooms.tsx` 변경과 `frontend/artifacts/`는 이번 배포에서 제외한다.

## 실제 보완한 세 차례의 검토

1. **구성**: 반복 안내/도구를 하단으로 옮기고 지수·자산·검색·목록의 순서를 정리했다. 모바일 자산을 숨기던 기존 CSS와 grid 배치 충돌을 보완했다. 최근 본 종목·상세 필터는 이름 있는 native details로 펼친다. 목록 필터는 전체 시장 통계가 아니다.
2. **읽기**: 라이트/다크 토큰을 구분하고 고정 금액과 통화 구분을 유지했다. 파란 자산 카드 위의 파란 손실 금액을 흰색으로 바꾸고 부호·항목명으로 의미를 유지한다. 어두운 테마에서도 검정 로고가 보이도록 실제 이미지 바탕은 흰색으로 유지한다. 주문 CTA의 흰 글자 대비를 보완했다. 확대 차트의 거래량 축은 원/달러가 아닌 `주`로 표시한다.
3. **조작·경계**: 차트는 한 인스턴스를 유지하고 모드 변경 시 확대 범위를 보존한다. 키보드 날짜 선택, Escape 닫기, 원래 버튼으로 포커스 복귀를 확인했다. 901~1023px에서 주요 메뉴가 모두 숨을 수 있는 경계를 정리했다. KOSPI 날짜 형식을 정규화하고 중복 날짜를 거절하며, 저장소 차단·조회 실패의 복구를 검사했다.

## 실행한 자동 검사

- `pnpm run verify:safety`: 기존 안전성 검사 15종 통과. 조회 제한시간/취소/경합, 통화 분리, 수량·예산, 미확정 주문 재확인, 기록·관심·분석·명세·캘린더·정기매수·기업정보·알림 초안·리그·라운지 복구를 포함한다. 기존 검사를 삭제하거나 느슨하게 만들지 않았다.
- `pnpm run verify:product`: 신규 11개 테스트 통과. 목록 조건·원래 순위·가격 단위, 날짜 공백/실제 MA20/거래량 0과 누락, 확대 한계, KOSPI 검증·실패 복구, dialog 포커스·스크롤 복귀, 단일 차트/관찰자 정리·실패 복구, 최초 테마 적용을 검사한다.
- `pnpm exec tsc --noEmit` 및 Next 빌드의 타입 검사 통과. 변경 TS/TSX·검증 스크립트의 ESLint 통과.
- `pnpm build --webpack`: 정적 페이지 24개 생성. 확대 차트 라이브러리는 `import()`로 선택적 로딩한다. 새 버전은 5.2.1로 고정하고 잠금 파일에는 해당 패키지와 fancy-canvas만 추가한다.

## 브라우저에서 확인한 흐름

승인된 `http://127.0.0.1:5264/`, `UPGRADE_FIXTURE=1`의 **격리된 결정적 자료**로 검사했다. 이 서버는 운영 API/DB에 연결하지 않고 일반 쓰기를 거절한다. 검증 화면에 보이는 지수·가격·잔액은 실제 운영 자료나 수익 사례가 아니다.

- 시장 → 한국/미국 목록 → 목록 내 검색 → 가격 범위 → 시장 전환 시 가격 조건 초기화. 검색 후 SK하이닉스는 원래 2위로 유지했다. 20개 더 보기로 40개가 되고 마지막 순위도 40으로 유지했다.
- 실제 종목 2개 선택 → 공개 식별자만 포함하는 비교 URL → 비교 화면 진입.
- 종목 상세 → 기본 차트 → 넓게 보기 → 실제 canvas 렌더링 → 일봉/MA20/확대/키보드 날짜 → Escape 닫기 및 포커스 복귀.
- 모바일 모의주문 열기·닫기: 주문 CTA와 하단 메뉴가 겹치지 않고 입력/위험 안내를 읽을 수 있다. 운영 주문을 제출하지 않았다.
- 관심종목의 회사명·가격·등락·별 버튼, 원화/달러 분리 자산, 기록의 회사명·매수/매도·수량·체결/대기와 금액을 확인했다. 오류 상태를 빈 성공으로 처리하지 않는다.
- 라이트/다크 전환과 320/360/390/430/768/915/1024/1440/1920 CSS px를 확인했다. 주요 화면의 페이지 가로 넘침을 측정했고, 915px 탐색 공백과 요약 grid 충돌을 발견해 수정했다. 최종 390/915/1440px를 재확인했으며 가로 넘침은 없었다. 최종 자산 카드의 손실 금액은 흰색으로 표시되고, 실제 로고 바탕도 흰색으로 유지되는 것을 계산 스타일과 화면으로 확인했다. 검증 탭의 콘솔 error/warn 기록은 없었다.

대표 시각 결과는 별도 로컬 `work/stockpilot-design-20261027/`에 보관한다. 저장소에는 개인 화면 캡처·생성물 전체를 올리지 않는다. OS 글자 확대·실제 Safari/Android WebView·스크린리더 전체 사용성 검사는 별도로 필요하다.

## 대비·성능의 측정 범위

토큰의 계산된 대비: 밝은 본문/흰 바탕 16.14:1, 밝은 보조 글자/보조 바탕 5.22:1, 브랜드 글자/선택 바탕 5.70:1, 상승 4.90:1·하락 5.58:1, 어두운 보조 글자/보조 바탕 7.52:1, 흰 CTA/브랜드 5.09:1. 이는 지정 색쌍의 계산이며 모든 화면의 WCAG 인증이 아니다. 초점·부호·텍스트 레이블·터치 타깃과 reduced-motion CSS를 유지한다.

확대 라이브러리 지연 로드와 차트 인스턴스 재사용을 확인했다. 실사용자 LCP/INP/CLS, 4만 명 부하, 접근성 인증 점수는 측정하지 않았으며 빌드 성공으로 대체 주장하지 않는다.

## 운영 확인·출판 상태

- 변경 전 운영 읽기 확인: KOSPI 실제 30포인트, 한국 시총 첫 20개/다음 페이지 존재, 삼성전자 일별 기록 80개 응답을 확인했다. 이는 새 웹 배포 검증과 구분한다.
- 코더스 기존 에이전트 토큰이 만료되어 재인증을 요청했다. 승인이 완료되기 전에는 새 배포 완료나 운영 검증 완료로 보고하지 않는다.
- 공개 시세의 이용 권한은 기존 운영자의 별도 승인 전제를 유지한다. SEC 기업정보는 기존 `SEC_USER_AGENT` 설정 여부에 따르며 이번에 새로 연결하지 않았다. 실계정 변경·실제 푸시·결제·리그 참여를 시험하지 않았다.

최종 배포는 승인 후 canonical upstream → 실제 fork 동기화/전체 SHA 비교 → 기존 Coders 프로젝트 → terminal 상태 → 운영 브라우저 확인 순서로 수행한다. `https://coders.kr/llms.txt`의 현행 배포 문서를 확인했다.
