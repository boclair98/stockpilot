# 금융권·증권사·거래소 연동 준비 목록

## 지금 제공하는 범위

StockPilot은 현재 `SIMULATION` 전용입니다. 기관 운영센터(`/operations`)에서
신규주문 일괄 중지, 주문 금액·횟수 한도, 시세 지연 차단, 원장 대사와 감사 추적을
관리합니다. 실거래 라우팅과 고객자산 보관 기능은 코드 수준에서 꺼져 있습니다.

## 지금 필요한 값

| 값 | 전달 방법 | 용도 |
|---|---|---|
| 운영자 Google 이메일 | 배포 Secret `OPERATOR_EMAILS` | 기관 운영센터 접근 허용 목록 |
| 서비스의 법적 운영 주체 | 계약 검토 문서 | 시장데이터·증권사 제휴 계약 주체 |
| 목표 고객 구분 | 기획 결정 | 사내 임직원, 일반 고객 교육, B2B 화이트라벨 중 선택 |

이메일은 저장소에 커밋하지 않습니다. API 키·서비스 계정 JSON·인증서·계좌
비밀번호는 채팅에 붙이지 말고 배포 Secret 또는 승인된 Secret Manager로만
전달합니다.

## 기관 서비스 전에 필요한 외부 계약/API

### 1. 국내 실시간 시장데이터

- KRX/코스콤 실시간·지연 데이터 상품 계약과 외부 표시·재분배 권한
- NXT Data Portal의 데이터 이용 및 네트워크 계약
- 상품 범위: 체결, 최우선/전체 호가, 예상체결, VI, 거래정지, 시장상태,
  종목마스터, 지수, 기업행사와 거래일 달력

개인 KIS Open API 시세는 개인의 자기 투자 목적이며 제3자 제공이 금지되어 있어
기관 고객용 화면의 상용 데이터 원천으로 사용하지 않습니다.

### 2. 증권사 제휴 API

- 한국투자증권 등 제휴법인 계약과 Authorization Code 기반 고객동의 흐름
- 제휴 샌드박스/검증계, 고정 IP 허용 목록, 호출 한도와 장애 연락망
- 주문, 정정·취소, 잔고, 주문가능금액, 체결통보, 미체결, 거래내역 API
- 주문번호의 멱등성 규칙, 오류코드 원장, 타임아웃 후 주문 조회·대사 규칙

실거래 단계에서는 개인용 App Key가 아니라 제휴 계약으로 받은 기관 자격증명과
고객별 위임 토큰을 사용해야 합니다.

### 3. 거래소 직접 연결을 목표로 한다면

직접 주문 연결은 공개 Open API 신청 문제가 아닙니다. 회원 자격 또는 회원사와의
계약, 전용망, 접속 규격, 인증시험이 필요합니다. 기관이 제공하는 최신 접속 문서에
따라 다음 정보를 받아 별도 어댑터를 만듭니다.

- FIX/전용 프로토콜 버전, SenderCompID/TargetCompID와 세션 시간
- mTLS/VPN 인증서, 전용망·DR 회선과 테스트 엔드포인트
- 주문·정정·취소·체결·거부 메시지 사전, 시퀀스 복구와 Drop Copy
- 시장별 가격단위, 수량단위, 호가유형, 세션·휴장·서킷브레이커 규칙
- 적합성·부하시험 시나리오와 운영 승인 증적

### 4. 이미 사용할 수 있는 보조 데이터

- OpenDART: 공시·재무·기업 주요정보(현재 연동됨)
- SEC EDGAR: 미국 상장기업 제출 이력·XBRL 재무정보(미국 공시 화면에 연동, `SEC_USER_AGENT` 필요)
- 금융투자협회 OpenAPI: 활용 신청·심사를 받은 범위의 자본시장 통계

금융투자협회 OpenAPI 약관에는 비상업적 이용 제한이 있으므로 유료 서비스에 넣기
전 별도 이용허락을 확인해야 합니다.

### 5. 국민은행 계좌정보를 붙이는 경우

모의투자 기능에는 은행 계좌 API가 필요하지 않습니다. 향후 사용자의 국민은행
잔액·거래내역을 선택적으로 보여주려면 개별 은행 비밀번호를 받지 않고 금융결제원
오픈뱅킹 이용기관 승인, 이용계약, OAuth 기반 사용자 동의, 접근토큰 보관·폐기,
정보제공 동의 이력과 철회 기능을 별도로 설계해야 합니다. 이 범위는 현재
StockPilot의 가상원장과 분리된 별도 프로젝트로 취급합니다.

## 연동 승인 후 개발 순서

1. 기관 Sandbox 자격증명과 샘플 전문으로 계약 테스트
2. 시장데이터 어댑터와 데이터 품질/지연 회로차단기 검증
3. 주문 어댑터를 모의 원장과 완전히 분리하여 구현
4. 사전 위험관리, 주문 상태머신, Drop Copy 대사와 수동 복구 도구 검증
5. 침투·부하·재해복구·장애훈련과 기관 적합성 시험
6. 제한 고객 파일럿 후 별도 승인으로 운영 전환

실거래 전환은 환경변수 하나로 켜지지 않으며, 별도 코드·보안심사·승인 배포를
요구하는 구조를 유지합니다.
